¿Qué es una migración?

El proceso de migración permite transferir datos desde archivos externos a nuestra base de datos de forma estructurada y controlada.

Nuestra herramienta valida el contenido de los archivos antes de su importación para:

  • Evitar errores comunes en la estructura de datos
  • Validar formatos y tipos de datos
  • Garantizar la integridad de la información
  • Transformar datos según reglas configuradas

Una vez finalizada la migración, podrás consultar los resultados detallados en la sección de control de migraciones.

Consejos para una migración exitosa

  • Asegúrate de que tu archivo tenga una estructura de columnas consistente
  • Elimina filas vacías o con datos parciales
  • Utiliza un nombre descriptivo para tu migración
  • Para archivos grandes, considera dividirlos en partes más pequeñas
