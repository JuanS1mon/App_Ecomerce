Análisis de datos

En esta página, puedes seleccionar tablas y columnas de una base de datos para realizar análisis de datos. La aplicación permite definir rangos de fechas y agregar campos adicionales para un análisis más detallado.

La página proporciona varias secciones de análisis, incluyendo indicadores clave de rendimiento (KPIs), gráficos dinámicos y tablas detalladas. Los usuarios pueden alternar entre estas secciones utilizando botones específicos.

Además, la aplicación permite realizar análisis avanzados como clustering, clasificación y regresión en los datos seleccionados. Los resultados de estos análisis se muestran en la sección correspondiente.

Consejo: Utiliza esta herramienta para obtener información valiosa de tus datos de manera eficiente y optimizar tu productividad en la gestión de información.
