Widget de Mensajes

Widget modular para mostrar notificaciones y mensajes en tiempo real. Se puede integrar en navbar, sidebar o cualquier contenedor.

🎯 Características

  • Notificaciones en tiempo real
  • Contador de mensajes no leídos
  • Panel desplegable
  • WebSocket automático
  • Diseño responsive

⚙️ Configuración

  • Posición personalizable
  • Límite de mensajes
  • Auto-refresh configurable
  • Filtros por tipo
  • Eventos personalizados

Widget de Chat

Widget de chat en tiempo real con WebSockets. Perfecto para chat flotante, soporte al cliente o comunicación de equipos.

🎯 Características

  • Chat en tiempo real
  • Múltiples salas
  • Indicador de escritura
  • Lista de usuarios
  • Notificaciones visuales

⚙️ Configuración

  • Salas personalizables
  • Usuario y avatar
  • Posición flotante/embebido
  • Auto-conexión
  • Límite de mensajes
