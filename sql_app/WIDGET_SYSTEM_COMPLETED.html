Chat y Mensajes como Componentes Modulares

📋 Resumen del Proyecto

Hemos convertido exitosamente los servicios de chat y mensajes en un sistema de widgets modular. Esto permite integrar estas funcionalidades en cualquier página web de forma sencilla y reutilizable.

🧩 Sistema Modular

  • Widgets independientes y reutilizables
  • Configuración flexible por widget
  • Carga dinámica de componentes
  • Integración con APIs existentes

💬 Widget de Chat

  • WebSocket en tiempo real
  • Interfaz responsiva
  • Múltiples posiciones de pantalla
  • Configuración personalizable

📨 Widget de Mensajes

  • Sistema de notificaciones
  • Gestión de mensajes no leídos
  • Interfaz administrativa
  • Conexión WebSocket opcional

💡 Uso de los Widgets

Integración Simple

<!-- Cargar el loader -->
<script src="http://127.0.0.1:8000/widgets/loader.js"></script>

<!-- Contenedor para el widget -->
<div id="mi-widget-container"></div>

<script>
// Cargar widget de mensajes
loadMessageWidget('mi-widget-container', {
    position: 'inline',
    showHeader: true,
    maxHeight: '400px'
});

// Cargar widget de chat
loadChatWidget('mi-chat-container', {
    position: 'floating',
    theme: 'dark'
});
</script>
