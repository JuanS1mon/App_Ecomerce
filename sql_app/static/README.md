# Mi App Web

Este proyecto es una aplicación web que utiliza Bootstrap para estilos y componentes predefinidos. 

## Estructura del proyecto

```
mi-app-web
├── css
│   └── estilo.css
├── js
│   └── script.js
├── lib
│   └── bootstrap
│       ├── css
│       │   └── bootstrap.min.css
│       └── js
│           └── bootstrap.min.js
├── index.html
├── about.html
├── contact.html
└── README.md
```

## Archivos

- `css/estilo.css`: Este archivo contiene los estilos CSS personalizados para la aplicación web.
- `js/script.js`: Este archivo contiene el código JavaScript personalizado para la aplicación web.
- `lib/bootstrap/css/bootstrap.min.css`: Este archivo es el archivo CSS de Bootstrap, que proporciona estilos y componentes predefinidos para la aplicación web.
- `lib/bootstrap/js/bootstrap.min.js`: Este archivo es el archivo JavaScript de Bootstrap, que proporciona funcionalidad interactiva y componentes para la aplicación web.
- `index.html`: Este archivo es el archivo HTML principal para la página de inicio de la aplicación web. Debe incluir los archivos CSS y JavaScript de Bootstrap y enlazar los archivos CSS y JavaScript personalizados.
- `about.html`: Este archivo es el archivo HTML para la página "Acerca de" de la aplicación web. Debe incluir los archivos CSS y JavaScript de Bootstrap y enlazar los archivos CSS y JavaScript personalizados.
- `contact.html`: Este archivo es el archivo HTML para la página de contacto de la aplicación web. Debe incluir los archivos CSS y JavaScript de Bootstrap y enlazar los archivos CSS y JavaScript personalizados.
- `README.md`: Este archivo contiene la documentación del proyecto.
