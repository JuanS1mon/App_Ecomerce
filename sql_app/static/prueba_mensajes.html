Instrucciones de Prueba

1. Verifique que aparece el ícono 🔔 en la navbar superior derecha

2. El badge debe mostrar el número de mensajes no leídos (14)

3. Haga clic en el ícono para abrir el dropdown de mensajes

4. Los mensajes deben aparecer con diferentes íconos y colores

5. Haga clic en un mensaje para marcarlo como leído

6. Use "Marcar todos como leídos" para limpiar notificaciones

Nota: Esta es una página de prueba para verificar el funcionamiento del sistema de mensajes con carga dinámica de componentes.
