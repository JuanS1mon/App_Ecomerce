Guía de Uso

En esta página, puedes mapear campos entre diferentes tablas de datos para facilitar la migración de información. Puedes arrastrar y soltar campos de una tabla a otra para establecer relaciones y conexiones entre los datos.

Cómo usar esta herramienta:

  1. Selecciona la tabla de origen y la tabla de destino en los selectores correspondientes.
  2. Arrastra un campo de la tabla izquierda hacia un campo de la tabla derecha para establecer una relación.
  3. Haz clic en un campo para cambiar su color y facilitar la visualización de las relaciones.
  4. Utiliza el botón "Limpiar Mapeos" para comenzar de nuevo si es necesario.
  5. Cuando hayas completado todos los mapeos necesarios, haz clic en "Migrar" para ejecutar el proceso.
