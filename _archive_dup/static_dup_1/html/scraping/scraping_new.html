Configuración de selectores

Los selectores definen qué información extraer de la página web. Use selectores CSS (recomendado) o XPath para identificar elementos específicos en la página.

Nombre identificativo del campo a extraer (sin espacios ni caracteres especiales). Este nombre se usará como identificador en los resultados.
Ej: titulo, precio, descripcion

Selector que identifica el elemento en la página. Se recomienda usar selectores CSS para mayor simplicidad.

Ejemplos CSS:
  • h1.product-title → Encabezado h1 con clase "product-title"
  • div.product span.price → Elemento span con clase "price" dentro de div con clase "product"
  • .description → Cualquier elemento con clase "description"

Especifica el tipo de dato a extraer:

  • Texto: Solo el texto del elemento (sin HTML)
  • HTML: Contenido HTML completo con formato
  • Atributo: Valor de un atributo específico
  • Enlace: URL del enlace (atajo para atributo 'href')
  • Imagen: URL de imagen (atajo para atributo 'src')

Nombre del atributo que desea extraer (solo necesario si el tipo es "Atributo").

Ejemplos comunes:
  • src - Para URL de imágenes
  • href - Para enlaces
  • alt - Para texto alternativo
  • data-* - Para atributos personalizados

Determina si se debe extraer uno o varios elementos:

  • No: Extrae solo el primer elemento que coincida
  • Sí (lista): Extrae todos los elementos coincidentes y los devuelve como una lista

Ideal para extraer características, comentarios u otros elementos repetidos.

El selector contenedor identifica elementos que contienen múltiples datos a extraer (por ejemplo, tarjetas de producto).

Al especificar un contenedor, los selectores de arriba se aplicarán a cada uno de los elementos que coincidan con este selector, generando múltiples registros.

Ejemplo:

Selector contenedor: div.product-card

Extraerá los campos definidos arriba para cada div con clase "product-card" en la página.

Si desea extraer múltiples elementos similares (como una lista de productos), especifique un selector de contenedor

Ejemplo práctico: Extracción de productos

Selector contenedor: div.product-card - Identifica cada tarjeta de producto

Campos a extraer:

  • titulo (Texto): h2.product-name
  • precio (Texto): span.price
  • imagen (Imagen): img.product-image
  • descripcion (HTML): div.description
  • url (Enlace): a.product-link

Opciones de red

Puede ser usado para interactuar con la página, hacer clic en elementos o manipular el DOM antes de la extracción.

Formato: minuto hora dia_del_mes mes dia_de_la_semana
