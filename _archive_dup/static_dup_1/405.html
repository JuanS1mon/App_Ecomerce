405

Método No Permitido

El método de solicitud no está permitido

La URL que intentas acceder existe, pero el método HTTP utilizado no está permitido para esta ruta. Por ejemplo, estás usando GET en una ruta que solo acepta POST.

Posibles causas:

  • Estás utilizando el método HTTP incorrecto para esta operación
  • El endpoint existe pero no acepta el método que estás utilizando
  • Estás intentando acceder a una API con un método no permitido
Ir al inicio

Si crees que esto es un error, por favor contacta al administrador del sistema.

Referencia: 405 Method Not Allowed
