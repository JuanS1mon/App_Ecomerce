🔐 Interceptor de Autenticación Embebido

Se implementó un interceptor JavaScript embebido directamente en cada página que:

  • • Intercepta automáticamente todas las peticiones fetch()
  • • Incluye automáticamente el header Authorization: Bearer {token}
  • • Maneja respuestas 401 limpiando tokens inválidos
  • • Proporciona navegación segura con navigateWithAuth()
